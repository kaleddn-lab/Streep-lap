
# STREETLAB | Streetwear

Tienda virtual de ropa urbana inspirada en la cultura streetwear.

## Descripción

STREETLAB es una tienda online diseñada con HTML, CSS y JavaScript. Cuenta con un diseño moderno, oscuro y adaptable a dispositivos móviles.

## Características

- Diseño responsive para computadoras y celulares.
- Catálogo de productos.
- Filtros por categoría.
- Carrito de compras interactivo.
- Almacenamiento del carrito en el navegador mediante localStorage.
- Cálculo automático del total en colones costarricenses.
- Generación de pedidos por WhatsApp.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Instalación

1. Clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo index.html en tu navegador.

## Configuración

Antes de recibir pedidos reales, cambia el número de WhatsApp de ejemplo en el archivo index.html por el número oficial de la tienda.
